# 報告書の体裁について

## 1. 提出基本事項
*   **提出形態**：個人提出（班ごとではない）
*   **ファイル形式**：**PDFファイル**
    *   Wordで作成後、必ずPDFに変換すること。
    *   **未変換（Wordのまま）は減点対象。**
*   **提出先**：WebClass『報告書』
*   **提出締切**：**1月27日（火）23:59**

## 2. 書式設定（ページ設定）
WebClassに掲載されているWord書式を利用し、以下の設定に統一すること。
**書式から外れている場合は大きく減点される。**

*   **用紙**：A4タテ
*   **余白**：上下左右 20 mm
*   **文字数／行数**：40文字 × 50行（1ページ最大2000字）
*   **文字配置**：両端揃い

## 3. フォント設定
*   **タイトル**：MS Pゴシック、太字、12pt
*   **見出し**：MS Pゴシック、太字、10.5pt
*   **本文（日本語）**：MS P明朝、10.5pt
*   **本文（英数字）**：Times New Roman、10.5pt

## 4. 分量（ページ数）の規定
*   **枚数**：**3枚以上 4枚以内**
*   **ノルマ**：**3枚目に到達していること。**
    *   2枚目までは必ず埋めること。
    *   ノルマ（3枚目突入）に届かないものは大きく減点。

## 5. 構成
構成は指定されないが、基本的には以下の順序とすること。

1.  **背景について**
    *   製品提案に至った社会問題などの背景、テーマの社会的意義。
2.  **既存・研究中の技術について**
    *   現状の取り組みや研究開発の状況、なぜ未解決なのか、既存技術の説明。
3.  **提案する製品について**
    *   考案した製品の具体的説明。
    *   新規性・独自性・提案の有意義性を示す根拠。
4.  **おわりに**
    *   報告書のまとめ（問題と提案製品の要約）。
    *   課題点や実現に必要なことへの言及。
5.  **参考文献**

## 6. 執筆上の禁止・注意事項（特記事項）
*   **箇条書きの禁止**：参考文献以外の部分では使用しないこと。文章で記述する。
*   **改行の制限**：無駄に改行しない。大きな話の転換以外では改行しないのが普通。
*   **図表の扱い**：
    *   内容説明に必要なものだけ挿入する（文章のみで説明可能な内容は図を入れない）。
    *   スペース稼ぎのための無用な大きさでの図の挿入や、無駄な図の挿入は大きく減点する。
*   **参考**：WebClassに掲載されている「みほんレポート」を参考にすること。
